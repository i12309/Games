# Руководство по новым модулям игр

Проект `Games` публикуется через **GitHub Pages** из корня `main`. Никакого backend и сложной сборки не требуется.

## Контракт модуля

1. Создать `games/<slug>/index.html`, отдельные `.css` и `.js`; движок игры не должен зависеть от JavaScript соседних игр.
2. Подключать общую тему по относительным ссылкам: `../../assets/styles.css`, `../../shared/game-base.css`, `../../shared/platform.js`.
3. Навигация в каталог: `../../index.html` (не `/Games/` и не `/index.html`, чтобы одинаково работало локально и в Pages).
4. Добавить карточку со ссылкой `games/<slug>/index.html` в корневой `index.html`.
5. Базовые настройки и прогресс хранить через `Igroland.read/write('slug.namespace.v1', value)`. Нельзя использовать локальный ключ другой игры.
6. На планшете не полагаться на hover. Интерактивные цели должны быть удобными для пальца; у Canvas необходим `touch-action:none`, если обрабатываются жесты.
7. Звук необязателен, выключен по умолчанию: `Igroland.sound(...)`, `Igroland.soundEnabled()` и `Igroland.setSound(...)`.
8. Проверять сохранённое состояние перед применением: localStorage может быть повреждён или недоступен.
9. Алгоритмы и правила по возможности держать в отдельном модуле без DOM, чтобы тестировать их в Node.
10. Добавить тест в `tests/` и проверить `node tests/smoke.js`, `node tests/new-games.js`.

## Критерии приёмки

- Глубокие ссылки `/Games/games/<slug>/` работают после публикации Pages, без CDN или абсолютных URL.
- Состояние восстанавливается после обновления вкладки (если localStorage доступен).
- Игра не ломается на ширинах 390, 768 и 1200px и не требует мыши.
- Новые сгенерированные уровни проходятся, а подсказки не рекомендуют запрещённые действия.
- Отмена, перезапуск, победа, ошибки ввода и достижение цели не вызывают исключений в консоли.
- Сохранённый прогресс иных игр не меняется.

## Примечания о детских интерфейсах

Не добавлять рекламу, внешние профили, рейтинги между детьми, навязчивые покупки, наказания за отсутствие активности и жёсткие таймеры. Подсказки и отмена должны помогать освоению механики. Не передавать пользовательские фото и историю игры внешним сервисам.
