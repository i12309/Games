# Коллекция раскрасок: 40 новых схем

Добавлено 40 оригинальных рисунков. Вместе с исходными восемью доступны 48 схем. Исходный `games/coloring/art-data.js`, идентификаторы и сохранённые клетки прежних рисунков не изменены.

## Вход

- Все рисунки: `games/coloring/gallery.html`.
- Самые сложные: `games/coloring/gallery.html?difficulty=master`.
- Прямой вход в рисунок: `games/coloring/index.html?level=more-coral-reef`.
- На главной появилась ссылка «Раскраски · 48 рисунков»; новые схемы участвуют в смешанной подборке уровней.

| Сложность | Новых рисунков | Размер сетки |
| --- | ---: | --- |
| Легко | 6 | 24×24 |
| Средне | 10 | 32×32 |
| Сложно | 12 | 40×40 и 48×48 |
| Очень сложно | 8 | 64×64 |
| Эксперт | 4 | 80×80 |

Четыре большие картины: «Большой коралловый риф» (6085 клеток, 21 цвет), «Тайны волшебного леса» (6128 клеток, 19 цветов), «Космопорт на Луне» (6084 клетки, 14 цветов), «Парк весёлых аттракционов» (6084 клетки, 18 цветов). Это самостоятельные композиции, а не масштабированные копии маленьких рисунков.

## Файлы и сохранения

`pixel-art.js` — детерминированный растеризатор целочисленных схем без DOM, внешних библиотек, сети или случайности. Восемь файлов в `games/coloring/packs/` описывают по пять рисунков. После выполнения каждый рисунок имеет тот же формат `palette` + `rows`, что и старые схемы. Точка означает пустую клетку, остальные символы адресуют цвета. Неиспользуемые цвета исключаются.

Пакеты: `01-garden`, `02-wonders`, `03-friends`, `04-wildlife`, `05-journeys`, `06-fairytales`, `07-worlds`, `08-grand-scenes`. Они подключены после исходного `art-data.js` и растеризатора, до кода игры/каталога/галереи.

Идентификаторы новых рисунков начинаются с `more-`. После публикации нельзя изменять геометрию, порядок цветов или растеризатор для существующего ID: сохранение адресует конкретные клетки. Для переработанной схемы нужен новый ID. Ключи остаются `igroland-pixel-paint-v1:progress:<id>`; галерея читает эти же данные, не мигрируя и не очищая чужие сохранения.

Разработка зафиксирована отдельными коммитами: сначала растеризатор, затем каждая партия из пяти рисунков, затем интерфейс и интеграция. GitHub Pages публикует готовые статические файлы без сборки приложения.

## Интерфейс

Галерея позволяет искать по названию и теме, фильтровать сложность и состояние (начатые, готовые, не начатые). На карточках показаны размер сетки, цвета, число непустых клеток и сохранённый процент. Параметры фильтров отражаются в URL. Фото остаются на устройстве; импорт собственной картинки сохранён в прежнем виде.

В игре добавлены ссылка на всю библиотеку, фильтр сложности, характеристики рисунка и кнопка «Крупно» для клеток примерно по 32 CSS-пикселя. Верхний предел увеличения — 24× вместо 7×; жесты и колесо используют этот предел. Процент 100 показывается только после последней клетки. На узких экранах список рисунков прокручивается горизонтально, на больших — внутри боковой панели.

Остаток по каждому цвету хранится в счётчике, а обновления палитры группируются по кадрам. История отмены в текущей сессии вмещает весь рисунок, включая сцены с более чем 6000 клетками. После перезагрузки восстанавливаются закрашенные клетки, но история отмены, как и раньше, не сохраняется. Прогресс привязан к браузеру и устройству; очистка данных сайта удаляет его.

## Проверки

```sh
node tests/smoke.js
node tests/new-games.js
node tests/mahjong.js
node tests/marble-shooter.js
node tests/learning.js
node tests/adventures.js
node tests/coloring-library.js
python tests/coloring-library-browser.py
```

Node-набор для раскрасок проверяет 40 новых + 8 исходных схем, уникальность ID и изображений, воспроизводимость, размеры строк, корректность цветов, пять уровней сложности, отсутствие пустых цветов в новых палитрах, относительные ссылки Pages и неизменность Git blob исходного `art-data.js`. Всего 76 886 непустых клеток.

Браузерный тест по умолчанию запускает локальный HTTP-сервер с префиксом `/Games/` и использует настоящий localStorage. Требуются Python Playwright и Chromium; путь к браузеру можно задать `CHROMIUM_PATH`.

В ограниченной среде разработки выполнен режим `COLORING_OFFLINE=1`: Chromium получает реальные HTML/CSS/JS через существующую фикстуру `browser_fixture.py`, а URL-параметры и хранилище имитируются. Это не проверка настоящего HTTP-развёртывания или физического планшета. Для запуска по частям предусмотрены `COLORING_TEST_MODE=links`, `COLORING_START`, `COLORING_END`, `COLORING_SKIP_DEEP`.

Проверены все 48 прямых входов, палитры, последняя клетка/победа/отмена, сохранённые клетки при повторном открытии, фильтры и поиск, размеры 390/768/1280, отсутствие горизонтального переполнения. Большой риф полностью раскрашен через обработчики Pointer Events (6085 клеток), затем отменены все 6085 действий. Проверено сохранение старого рисунка и ключа другой игры. Ошибок JavaScript не зарегистрировано.

Проверка Safari, реального планшета, системных жестов и ограничений localStorage на конкретном устройстве остаётся ручной. Все имеющиеся Node-наборы старых игр также выполнены успешно; их движки не изменены.
