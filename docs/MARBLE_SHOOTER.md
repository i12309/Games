# Шариковый лабиринт — правила, архитектура и приёмка

**Адрес:** `games/marble-shooter/index.html?level=1` (в Pages: `/Games/games/marble-shooter/`).

Оригинальная детская игра в жанре *marble shooter*, не использует графику или звук Zuma. Работает полностью в браузере, без сервера, сборки, библиотек, рекламы и внешних сетевых запросов.

## Правила

1. Цветная цепочка движется по кривой дорожке к выходу со звёздочкой.
2. Нажатием мышью/пальцем игрок стреляет шариком из пушки по цепочке.
3. Попадание вставляет шарик до/после ближайшего шара по проекции в касательное направление дорожки. Три или больше одинаковых соседних шара исчезают.
4. Исчезновение соединяет соседние фрагменты; повторные совпадения исчезают как цепная реакция, приносят больше очков.
5. Победа — полностью разобрать цепочку. Если голова цепочки достигла звёздочки, можно начать заново. Отмена доступна для нескольких последних выстрелов.
6. Для младших детей по умолчанию включён медленный режим «Малыш» (до трёх цветов). В режимах «Обычный» и «Эксперт» больше цветов и выше скорость.

## Уровни

10 маршрутов с зеркальными вариантами, постепенно растущим количеством шариков и цветностью. Парные группы генерируются с фиксированным seed по уровню и режиму; тест проверяет конструктивное решение — добавление одного подходящего шара к каждой паре. Свободная игра не гарантирует успешного попадания с любого угла или выигрыш после произвольных ошибок — для этого есть отмена и повтор.

## Бонусы

- **Заморозка:** 8 секунд замедления (за каждые 3 успешных попадания).
- **Взрыв:** заряд для удаления соседних шариков по 2 с каждой стороны (каждые 5 попаданий).
- **Назад:** отодвигает голову цепочки на 210 логических пикселей (каждые 7 попаданий).

## Управление

- **Планшет:** касание/отпускание стреляет, двумя пальцами можно изменять масштаб и перемещать игровое поле. Неполный жест двумя пальцами не должен стрелять случайно.
- **Мышь:** наведение и клик для выстрела, колесо для масштаба.
- **Клавиатура:** стрелки меняют направление, пробел стреляет, `S` меняет заряд, `P` ставит на паузу, `Ctrl/Cmd+Z` отменяет последний выстрел.
- Кнопки масштабирования/сброса, подсказок, звука и паузы доступны на всех экранах.

## Структура

- `levels.js` — 10 маршрутов, палитра, три режима сложности, плавное семплирование кривых Catmull–Rom по длине дуги; CommonJS для Node-тестов.
- `engine.js` — независимая от DOM симуляция: цепочка, движение, стрельба, поиск пересечений отрезка с шарами, вставка, цепные реакции, бонусы, сохранение/откат; CommonJS для Node-тестов.
- `renderer.js` — Canvas 2D, визуализация дорожки, шариков, пушки, эффектов, логический viewport и масштабирование.
- `game.js` — UI, события `PointerEvent`, клавиатура, прогресс по уровню и режиму, звуки из `Igroland`, жизненный цикл.
- `style.css`, `index.html` — интерфейс, адаптивное расположение и кнопки.
- `tests/marble-shooter.js` — генерация, алгоритмы и состояние без браузера.

Весь JavaScript — локальный. Прогресс хранится в `igroland.marble.level.v1.<mode>.<level>`, достижения — в `igroland.marble.completed.v1`. Во время ухода в фон игра ставится на паузу, чтобы ребёнок не проиграл из-за переключения вкладки. Очистка данных сайта удалит локальный прогресс.

## Приёмочные проверки

```bash
node tests/marble-shooter.js
node tests/smoke.js
node tests/new-games.js
node tests/mahjong.js
```

Для браузера проверить 390, 768 и 1280 px: реальный выстрел по видимой паре, отмену, масштабирование двумя пальцами без выстрела, смену режима с независимым сохранением, паузу/возобновление и отсутствие ошибок в консоли. В браузере звуковая система включается только по желанию; внешние файлы не запрашиваются.
