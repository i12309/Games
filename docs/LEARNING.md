# Учимся играя: первый учебный раздел Игроланда

Добавлены четыре самостоятельные игры и 16 тем. Старые восемь игр, их движки, настройки и сохранения не меняются. Целевая ступень — ребёнок 5–7 лет, который уже знает буквы и цифры, читает по слогам, но только начинает арифметику. Возраст не используется как обязательное ограничение или автоматическая оценка способностей.

## Содержание

| Модуль | Темы | Занятие |
| --- | --- | --- |
| `number-garden` — Числовой сад | Количество и ноль; сравнение; состав числа; сложение до 5; сложение до 10; вычитание до 10; дополнительное сложение с переходом через 10 | 5 заданий |
| `reading-stories` — Читаем истории | Короткие фразы; предложения; маленькие истории с причинными связями | 6 заданий по двум историям |
| `logic-lab` — Лаборатория закономерностей | Повторяющиеся группы; сравнение по форме; последовательности событий | 5 заданий |
| `robot-route` — Маршрут робота | Первые команды; препятствия; получение и доставка посылки | 5 заданий |

Чтение: 12 самостоятельно написанных текстов, по четыре на ступень; в каждом два вопроса и сборка первого предложения по образцу. Все ответы на вопросы связаны с текстом. Порядок слов проверяется **именно по показанному образцу**: приложение не объявляет другие грамматически допустимые русские предложения ошибочными вообще. Слоговые границы размечены вручную; автоматического деления произвольных слов нет.

## Учебная механика

1. При первом открытии темы показывается объяснение с интерактивным примером.
2. Затем ребёнок решает небольшую серию заданий. Переход после правильного ответа — только по кнопке, чтобы успеть прочитать объяснение.
3. Неверный ответ не отнимает жизнь и не завершает игру. Можно повторить попытку, открыть подсказку или вернуться к примеру.
4. В конце предлагается действие без экрана: кубики, книга, настоящий узор или маршрут игрушки.

Нет таймера, рейтинга детей, ежедневной серии, награды за скорость или автоматического перехода к более сложной теме после одного правильного ответа. Темы выбираются свободно. Текущая версия **не диагностирует развитие, не измеряет IQ, не оценивает произношение и не обещает общего повышения интеллекта**.

Арифметика начинается с предметов. Первые два примера на сложение используют положительные слагаемые и добавление 1/2; сложение с нулём появляется позже. В сравнении и составе числа каждая группа имеет свой счётчик касаний. Переход через десяток показан двумя десятиклеточными рамками. Отрицательных результатов нет.

Маршрут робота задаётся в абсолютных направлениях экрана. Генератор добавляет препятствие только при сохранении маршрута, проверенного поиском в ширину. Для доставки состояние поиска включает факт получения посылки. Во время запуска редактирование отключено; смена темы отменяет все оставшиеся таймеры. После ошибки программа остаётся для исправления.

## Архитектура

- В каждой новой папке: `index.html`, чистый модуль `rules.js`, браузерный `game.js`.
- `shared/learning-core.js`: детерминированная случайность, перемешивание, валидация и переходы учебной сессии; работает без DOM.
- `shared/learning.js`: общий экран темы, объяснение, подсказки, краткие сессии, сохранение, итог и блок для взрослого. Не подключается к прежним играм.
- `shared/learning.css`: стили только нового раздела; крупные кнопки, клавиатура и касания, адаптивная боковая панель.
- `assets/learning-registry.js`: реестр четырёх учебных модулей с тем же контрактом, что у игрового реестра.
- `assets/learning-home.js`: композиция двух реестров **перед** существующим `catalog.js`. Старый `game-registry.js` остаётся реестром развлекательных игр. В браузере `IGROLAND_ALL_GAMES` содержит всё, а `IGROLAND_GAME_REGISTRY` — выбранный раздел.
- `index.html?section=learn`: только обучение. `?section=play`: прежние игры. Без параметра: всё вместе. Случайный герой и смешанная подборка работают внутри выбранного раздела.

Все пути относительные. Никакой сборки, нового сервера, CDN или дополнительного workflow GitHub Actions. Публикация использует существующий GitHub Pages из `main`.

## Сохранение и результаты

Ключи: `igroland.learning.<module>.v1`. Для каждой темы сохраняются seed, номер текущего задания, завершённость ответа, ошибки, помощь и черновик (выбранные слова/команды/счёт предметов). Задание восстанавливается из seed, а не из недоверенного произвольного текста. Внутри каждой игры сохраняются не более 60 завершённых занятий.

«Самостоятельно» в отчёте — правильный ответ с первой попытки без подсказки, разбора отдельного слова и озвучки. Это **условная характеристика выполнения задания**, а не медицинская/педагогическая диагностика. Слоговая подсветка и предметные модели остаются учебными опорами; показатель не означает измерения беглости чтения или устного счёта. Касание ягод и построение маршрута — часть задания, а не наказуемая помощь.

Одинаковый завершённый ответ нельзя учесть дважды при перезагрузке. Повреждённый JSON или структура сессии сбрасываются безопасно. При недоступности записи появляется предупреждение, но занятия продолжаются. Кнопка сброса требует подтверждения и касается только выбранной учебной игры. Пользователей/аккаунтов и синхронизации между устройствами пока нет.

## Озвучка и приватность

Озвучка запускается только явной кнопкой и использует только русский `speechSynthesis`-голос с `localService === true`. Если такого голоса нет или API недоступен, показывается текстовое объяснение; сетевой голос не подставляется. Это опциональная возможность устройства, а не гарантированное аудиосопровождение на каждом планшете. Микрофон не запрашивается. Сайт не отправляет учебные результаты внешнему сервису.

## Проверки

```bash
node tests/learning.js
# Существующие тесты остаются доступными и не переписываются под новую реализацию:
node tests/smoke.js
node tests/new-games.js
node tests/mahjong.js
node tests/marble-shooter.js
```

Новый Node-набор проверяет 10 500 арифметических вариантов, 432 варианта заданий по чтению, 2250 логических заданий, 2400 решаемых карт робота, структуру ручной слоговой разметки, единственность правильных вариантов, восстановление сессий, самостоятельные/поддержанные ответы, ссылки всех 16 тем и относительные ресурсы.

Браузерная проверка новых модулей: прохождение всех 16 тем, неверные ответы, подсказки, восстановление, отсутствие двойного учёта, очистка таймеров, ширины 390/768/1280 и касания. В среде разработки сетевые переходы Chromium запрещены политикой, поэтому DOM-проверки выполнялись с локально встроенными JS/CSS и тестовым хранилищем. Это не проверка реального планшета, нативного localStorage на конкретном устройстве или HTTP-публикации Pages. Старые движки не изменены; их полный актуальный набор тестов в этой сессии не запускался.

## Методические ориентиры и ограничения

Основой дизайна стали общие принципы, а не перенесённая готовая методика:

- IES / What Works Clearinghouse, *Teaching Math to Young Children*: постепенное освоение числа и операций, отдельная работа с формами и закономерностями, учёт текущих знаний ребёнка. https://ies.ed.gov/ncee/wwc/practiceguide/18
- UK Department for Education, *Reading comprehension*: обсуждение смысла текста и слов, вопросы к прочитанному, последовательное расширение опыта чтения. https://help-for-early-years-providers.education.gov.uk/areas-of-learning/literacy/reading-comprehension

Эти источники не доказывают эффективность именно данного приложения и не являются русскоязычной школьной программой. Материалы приложения ещё не проходили независимую экспертизу педагога. Совместное чтение, разговоры, движение, рисование и реальные предметы не заменяются экранными заданиями.
