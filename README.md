# Игроланд — 7 детских игр в браузере

Небольшая библиотека игр на **чистых HTML, CSS и JavaScript**. Рассчитана на планшеты, телефоны и компьютер. Без аккаунтов, внешних библиотек, рекламных скриптов, backend и сборки.

- **Репозиторий:** https://github.com/i12309/Games
- **Сайт (после включения Pages):** https://i12309.github.io/Games/

## Главная страница

- Наверху показывается **случайная игра** с описанием, иллюстрацией, кнопкой запуска и кнопкой «Другая игра».
- Ниже располагаются карточки всех семи игр.
- Внизу отображаются **12 случайных уровней из разных игр**. Каждая подборка гарантированно включает хотя бы один уровень каждой игры. Кнопка «Другие уровни» меняет карточки.
- Нажатие открывает **именно выбранный уровень**, включая уровень сложности для «Найди пару», «Лабиринтов» и «Числовых сот», номера уровней для гаек и стрелок, раскладки маджонга и рисунки раскраски.
- Реестр игр и стартовых уровней хранится в `assets/game-registry.js`. Не нужно вручную дублировать карточки в HTML.

## Маджонг-пасьянс

Это **одиночный маджонг-пасьянс**, а не традиционный маджонг на четырёх игроков.

**Правило:** нажми на две одинаковые фишки. Фишка доступна, когда она не накрыта другой фишкой сверху и имеет свободную левую **или** правую сторону. Две выбранные свободные одинаковые фишки исчезают. Цель — полностью разобрать фигуру.

Раскладки: **Цветочный сад** (16), **Зверята** (24), **Фонарики** (28, 2 слоя), **Старинный храм** (44, 2 слоя), **Черепашка** (68, 3 слоя).

- `games/mahjong/rules.js` — детерминированный генератор и правила без DOM (можно запускать Node-тесты).
- Новые раскладки построены с **проверенным путём полного разбора**. Если игрок выбирает другую допустимую пару и заходит в тупик, можно отменить ход или перемешать оставшиеся фишки. Перемешивание, если геометрически возможно, снова создаёт решаемую последовательность.
- Подсказка использует проверенный план. После альтернативных ходов движок ограниченно ищет корректное завершение; если гарантированного пути не найдено, предлагает отмену/перемешивание, не выдумывая ход.
- Отмена восстанавливает и пары, и перестановку фишек. Состояние каждого уровня сохраняется через `Igroland` и `localStorage`.
- Доступно управление мышью и пальцами, перетаскивание поля, масштабирование двумя пальцами, кнопки увеличения/уменьшения и адаптация под маленький экран.
- Звук по умолчанию отключён.

## Размещение через GitHub Pages

1. Открыть **Settings → Pages** репозитория.
2. **Build and deployment → Source:** `Deploy from a branch`.
3. **Branch:** `main`; папка `/(root)`; нажать **Save**.
4. Каталог: https://i12309.github.io/Games/.

Это **project page** в подкаталоге `/Games/`, поэтому все ссылки должны быть относительными, например `../../assets/styles.css`, а не `/assets/styles.css`. В корне есть `.nojekyll`. После push в `main` GitHub публикует обновлённые статические файлы автоматически, если Pages настроены на эту ветку.

Для локального запуска желательно HTTP (из корня репозитория):

```bash
python -m http.server 8080
# http://localhost:8080/
```

Браузер иногда ограничивает `localStorage` и Worker при открытии через `file://`.

## Тесты

```bash
node tests/smoke.js
node tests/new-games.js
node tests/mahjong.js
```

`mahjong.js` проверяет 1250 раскладок до полной победы, восстановление решения после перемешивания, базовые правила блокировок, каталог и относительные ссылки. `new-games.js` дополнительно проверяет 140 раскладок гаек, 135 карт стрелок и 120 партий сот. Браузерные проверки выполнены на ширинах 390, 768 и 1200 пикселей, включая реальную работу DOM интерфейса в Chromium.
