# Игроланд (Games) — детский каталог мини-игр (v0.2)

Три независимые игры для компьютера, телефона и планшета. Чистые **HTML, CSS и JavaScript**; без серверов, аккаунтов, сборщиков, зависимостей, рекламы и внешних запросов.

## Публикация на GitHub Pages

Репозиторий: **https://github.com/i12309/Games**  
Каталог после включения GitHub Pages: **https://i12309.github.io/Games/**

Это статический сайт. Для публикации не нужны Node.js, npm, Docker, CI для сборки или отдельный сервер.

**Первоначальная настройка (однократно, владелец репозитория):**

1. Открыть `Settings` → `Pages` в репозитории `i12309/Games`.
2. В разделе `Build and deployment` выбрать `Source: Deploy from a branch`.
3. Выбрать `Branch: main` и `Folder: / (root)` и нажать `Save`.
4. После завершения первой публикации открыть [каталог](https://i12309.github.io/Games/).

При последующих коммитах в `main` GitHub Pages обновляет сайт автоматически. Настройка нужна только однажды.

**Важно для новых игр:** сайт доступен в подпапке `/Games/`, поэтому ссылки на CSS/JS и каталог должны быть относительными (`../../assets/styles.css`, `../../index.html`) либо учитывать базовый URL проекта. Не использовать пути от корня домена (`/assets/…`, `/games/…`).

Содержимое `README.md`, `tests/` и `.nojekyll` не требует исполнения серверного кода. Тесты можно запускать локально.

## Запуск

1. Распаковать архив с сохранением структуры каталогов.
2. Открыть `index.html` в браузере.
3. Выбрать игру. На планшете удобнее открывать опубликованный сайт по HTTPS (например, через GitHub Pages).

Для локального тестирования с компьютера можно выполнить:

```sh
python -m http.server 8080
```

и открыть `http://localhost:8080`. Для планшета на том же Wi-Fi использовать локальный IP компьютера и порт `8080`, если правила сети и брандмауэра разрешают подключение.

На `file://` само приложение работает, однако некоторые браузеры могут ограничивать сохранение в `localStorage`. Для гарантированного сохранения лучше использовать локальный HTTP-сервер или HTTPS.

## Игры

### Раскраска по номерам — `games/coloring/index.html`

- 8 готовых изображений от простого к сложному.
- Загрузка своей фотографии и преобразование в сетку с 4–10 номерами цветов.
- Поддерживаются масштабирование/перетаскивание пальцами, мышь, подсказка-образец и отмена действий.
- Состояние встроенных рисунков сохраняется на устройстве (localStorage), исходные фото никуда не отправляются.

Обратная совместимость: старый URL `game.html?level=heart` перенаправляет на `games/coloring/index.html?level=heart`.

### Найди пару — `games/memory/index.html`

- Три сложности: **3, 6 или 10 пар**.
- Нажатием открывать две карточки. Совпавшие остаются видимыми; остальные закрываются автоматически.
- Кнопка подсказки кратко показывает пару; подсказки не учитываются в рекорде без подсказок.
- Ходы, таймер, рекорды и сохранение текущего расклада по каждой сложности.
- Дополнительные звуки по желанию (по умолчанию выключены).

### Лабиринты — `games/maze/index.html`

- Три размера: **7 × 7**, **11 × 11**, **15 × 15**.
- Каждый лабиринт генерируется алгоритмом обхода в глубину со снятием стен, поэтому из старта к цели всегда есть путь.
- Перемещение героя: ведение пальцем по дорожке, касание соседней клетки, стрелки на экране или стрелки / WASD с клавиатуры.
- Масштаб и движение поля — двумя пальцами, колёсико мыши, правой кнопкой мыши или кнопками масштаба.
- Кнопка подсказки выделяет следующий шаг кратчайшего пути. Подсказки не учитываются в рекорде без подсказок.
- Сохраняются карта, положение героя, ходы, время и рекорды по каждой сложности.

## Структура

```text
igroland/
├── index.html                  Каталог игр
├── game.html                   Старая ссылка на раскраску (перенаправление)
├── assets/
│   ├── styles.css              Базовая тема и стили каталога/исходной раскраски
│   └── catalog.js              Превью готовых рисунков
├── shared/
│   ├── game-base.css           Общие элементы оформления игр
│   └── platform.js             localStorage, таймер и необязательные звуки
├── games/
│   ├── coloring/
│   │   ├── index.html
│   │   ├── coloring.js          Раскрашивание, масштабирование, загрузка изображения
│   │   └── art-data.js          8 схем рисунков
│   ├── memory/
│   │   ├── index.html
│   │   ├── memory.css
│   │   └── memory.js
│   └── maze/
│       ├── index.html
│       ├── maze.css
│       └── maze.js
└── tests/
    └── smoke.js                Проверка логики на Node.js
```

Каждая игра изолирована в `games/<slug>/`. Общие компоненты находятся в `shared/`, а каталог содержит ссылки на самостоятельные страницы. Добавление новой игры не требует изменения JS других игр: достаточно сделать новый каталог `games/<slug>/` и добавить карточку в `index.html`. В следующих версиях можно вынести карточки в единый реестр (manifest), чтобы каталог собирался автоматически.

## Проверки

Команда для логических тестов (нужен Node.js 18+):

```sh
node tests/smoke.js
```

Проверяются: открытие/совпадение/закрытие карточек, победа, подсказки, рекорды, восстановление после перезапуска, генерация 90 проходимых лабиринтов, завершение маршрута, масштаб, перемещение с сенсорного события и восстановление карты.

**Важно:** тесты логики не заменяют проверку на конкретной модели планшета: реальный жест двумя пальцами, размеры элементов, поведение мобильного браузера нужно дополнительно проверить на устройстве.

## Приватность

Приложение не отправляет изображения, прогресс или статистику на сервер. Всё выполняется локально в браузере. Сохранение привязано к конкретному браузеру/домену — при удалении данных сайта или смене устройства прогресс может исчезнуть.
