# Игроланд — 6 игр для планшета и браузера

Каталог мини-игр на **чистых HTML, CSS и JavaScript**, без сервера, аккаунтов, рекламных SDK, сборщиков или CDN. Каждая игра — отдельная папка. Игровые данные и результаты остаются на устройстве в `localStorage`.

- Репозиторий: https://github.com/i12309/Games
- После включения GitHub Pages: https://i12309.github.io/Games/

## Игры

| Игра | Страница | Возможности |
| --- | --- | --- |
| Раскраска по номерам | [`games/coloring/`](games/coloring/index.html) | Готовые схемы, пикселизация своих фото, палитра, масштаб пальцами, сохранение |
| Найди пару | [`games/memory/`](games/memory/index.html) | 3 сложности, совпадающие карточки, подсказки и рекорды |
| Лабиринты | [`games/maze/`](games/maze/index.html) | Генерация проходимых карт, маршрут, подсказки, масштаб и управление пальцами |
| **Сортировка гаек** | [`games/nuts/`](games/nuts/index.html) | Номерные уровни, от 3 до 8 цветов, 2 запасных болта, отмена, подсказка и сохранение |
| **Распутай стрелки** | [`games/arrows/`](games/arrows/index.html) | Изогнутые стрелки, геометрическая проверка столкновений, 3 сердечка, подсказки, жесты и уровни |
| **Числовые соты** | [`games/hexmerge/`](games/hexmerge/index.html) | 3 сложности, соседние одинаковые числа, цепные объединения, очки, рекорды и сохранение |

Все активные игры доступны из `index.html`. Ссылка `game.html` оставлена для совместимости со старой раскраской.

## Размещение через GitHub Pages

1. В репозитории открыть **Settings → Pages**.
2. В **Build and deployment → Source** выбрать `Deploy from a branch`.
3. Выбрать ветку `main` и папку `/(root)`, нажать **Save**.
4. После публикации каталог будет доступен по адресу https://i12309.github.io/Games/.

Дальнейшие обновления опубликованных файлов из `main` не требуют отдельной сборки. `.nojekyll` уже добавлен. Поскольку это project page, сайт обслуживается из `/Games/`: **использовать относительные URL**, никогда не `/games/…` или `/assets/…` от корня домена.

Работает полностью локально, без подключения к интернету после загрузки ресурсов (в браузере `file://` может ограничивать `localStorage` и Web Worker). Для локальной проверки желательно HTTP:

```sh
python -m http.server 8080
# открыть http://localhost:8080
```

## Новые игры: детали и ограничения

### Сортировка гаек

- Вместимость болта — 4 гайки. Переносится **только верхняя** и только на пустой болт или совпадающий верхний цвет.
- Каждый уровень берётся из исходного набора заранее проверенных схем и детерминированно перемешивается: запуск мгновенный, решение гарантировано.
- Встроенная последовательность решения доступна для подсказок. После альтернативного хода подсказка ищется в Web Worker; если поиск не находит пути за установленный лимит, игра предложит отменить шаг, не выдумывая ход.
- Прогресс и история отдельно по уровням, кнопки отмены и перезапуска, звук по желанию.

### Распутай стрелки

- Фигура — непрерывная непересекающаяся ломаная. Острие определяет направление её выхода с поля.
- Свободной считается стрелка, перед которой **нет другой фигуры вдоль пути движения всех сегментов** до выхода за границу.
- Генерация включает проверку графа зависимостей: существует корректный порядок полного освобождения всех фигур. Ошибочные нажатия расходуют сердечки, ход можно отменить.
- Управление: касание/клик стрелки; перетаскивание одним пальцем или мышью для панорамирования; два пальца для изменения масштаба; колёсико и кнопки +/-.

### Числовые соты

- Игровое поле — расположенные со смещением шестиугольники, шесть направлений соседства.
- Касание клетки с равным соседом объединяет пару в число вдвое больше. Если рядом появляется ещё один равный блок, запускается цепочка объединений.
- После объединения блоки оседают вниз, свободные клетки заполняются новыми. Генератор гарантирует наличие хотя бы одного доступного объединения; тупика из-за случайной раздачи нет.
- 3 уровня сложности: цели 64, 128, 256. Состояние, история и лучшие результаты хранятся отдельно.

## Автоматические тесты

```sh
node tests/smoke.js
node tests/new-games.js
```

`new-games.js` проверяет 140 решаемых уровней гаек, 135 вариантов стрелок с пошаговым прохождением, 120 партий сот до достижения цели, а также наличие всех локальных ссылок для GitHub Pages. Все игровые модули используют отдельные пространства ключей `localStorage`.

Дополнительно выполнены браузерные проверки Chromium для трёх ширин (десктоп / планшет / телефон), открытие модулей, действия в играх и прохождение новых игр до победы. Реальное устройство может иметь особенности жестов и масштабирования, которые следует проверять отдельно.

## Принципы добавления следующих игр

См. [`docs/GAME_MODULE_GUIDE.md`](docs/GAME_MODULE_GUIDE.md). Новые страницы размещаются в собственной `games/<id>/`, используют общие компоненты из `shared/` и относительные ссылки, тестируются отдельно и регистрируются карточкой в `index.html`. Существующие игровые движки не изменяются без необходимости.

## Конфиденциальность

Все изображения, история ходов и рекорды обрабатываются локально. Сайт не делает запросов к аналитике или рекламным сервисам. Очистка данных сайта или смена браузера может удалить сохранённый прогресс.
