# Игроланд — играем, учимся и придумываем

**16 игр и мастерских** на чистых HTML/CSS/JavaScript. Для планшета и компьютера,
без регистрации, рекламы, внешних игровых библиотек, backend и сборки.

Шариковая мастерская — **не ещё одна Zuma**, а конструктор физических трасс:
жёлобы, воронки, пружины, шесть задач и свободный режим. Можно запускать один или
три шарика, останавливать движение, переставлять детали и сохранять трассы.

## Мои работы

Общая локальная полка для картинок из фигур и шариковых трасс. До 24 работ, открытие,
редактирование, точечное удаление, экспорт/импорт JSON. Полка не синхронизируется
между устройствами: для переноса нужен файл. Очистка данных сайта удаляет прогресс.

## Запуск и GitHub Pages

```sh
python -m http.server 8080
# http://localhost:8080/
```

Pages: **Settings → Pages → Deploy from a branch → main → /(root)**.
Все ресурсы используют относительные пути; `.nojekyll` находится в корне.
Глубокие ссылки имеют вид `games/forest-shop/index.html?level=total`.
Старый адрес `game.html` сохранён для раскраски.

После push в `main` обновление публикует штатный Pages workflow. Дополнительных
workflow для тестов и отдельных артефактов проект не создаёт.

## Архитектура

Каждая игра находится в собственной папке `games/<slug>/`. Правила и генераторы
по возможности отделены от интерфейса. `shared/platform.js` отвечает за простое
локальное хранение и опциональный звук. Учебная оболочка — `shared/learning*.js`.
Общие функции новых конструкторов и полка — `shared/workshop.js`.

Каталог собирается из `assets/game-registry.js`, `assets/learning-registry.js`,
`assets/adventures-registry.js`. Фильтры применяет `learning-home.js`, карточки и
случайную подборку рисует `catalog.js`. В общей подборке теперь по одному уровню
каждой из 16 игр; отдельный раздел показывает только соответствующие игры.

## Тесты

```sh
for file in tests/*.js; do node "$file"; done
# Для браузерных тестов нужны Python playwright и установленный Chromium:
CHROMIUM=/usr/bin/chromium python tests/adventures-browser.py
```

У браузерных тестов есть группы для короткого запуска:
`shop1`, `shop2`, `post`, `shapes1`, `shapes2`, `shapes3`, `editor`, `physics`, `shelf`, `layouts`.
Ресурсы встраиваются локально; параметры URL и хранилище заменяются тестовыми.
Это не проверка реального планшета, Safari или HTTP-публикации.

## Приватность

Задания, фотографии и работы обрабатываются в браузере. Нет аналитики, профилей
детей, рекламы или серверной отправки фотографий. Экспорт JSON выполняется только
по кнопке пользователя. Результаты зависят от доступности локального хранилища.
